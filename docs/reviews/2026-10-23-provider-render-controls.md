# Online Gemma 摘要與三模式文字控制修正

主人於 2026-10-23 提供兩張實機圖：翻譯及遠端模型清單檢查已成功，主視窗仍顯示「金鑰已設定，連線未驗證」；氣泡／截圖模式的字級與位移控制整組停用。本切片修正這兩條可重現路徑，沒有修改線上模型或額度，也沒有把一般「翻譯完成」訊息當成特定 provider 的連線證據。

Online Gemma 的摘要原本只讀金鑰是否為空，僅 Luna 接上連線結果。現在讀取既有背景模型探索的即時結果：檢查中顯示檢查中，成功且目前模型確實在清單中才顯示金鑰與模型存取已驗證。離線快照不冒充當次驗證；更換金鑰會撤銷舊結果並推進 generation，延遲返回的舊請求無法覆蓋新狀態。沒有新增輪詢或額外 API 請求；模型清單成功不保證生成額度或文字／圖片翻譯皆成功。

字級與位置同時有 UI 停用和排版忽略的問題。三種模式現在啟用共用控制，氣泡／截圖排版使用保存的字級與偏移；串流與最終字幕走同一套配置。截圖模式保留自動選側，再套用偏移並限制在 overlay 邊界；浮雕既有配置保留。設定仍使用 region_relief_* 鍵，沿用原有保存／載入與範圍限制。透明度是選區框的透明度，沒有改成文字透明度，也沒有新增拖曳字幕功能。

新增標題與提示先由 Codex 做必要的功能對齊。橋接自動選擇 Gemini 4 Argon High 時回報 429；主人指出 Flash 仍有額度後，確認即時目錄並在同一 cascade 明確切至 Gemini 3.8 Flash High，成功取得最終三語 JSON。最終採用 Flash 交稿，逐字核對六個字串；不把先前高階模型的錯誤泛稱為所有 Gemini 模型不可用。證據在本機 output/ui-fixes-20261023/gemini-copy.json。
