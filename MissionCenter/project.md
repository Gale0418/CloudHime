# 專案

- 專案：CloudHime demo 籌備與商業化
- 週期：2026-04-29 Demo Readiness
- 目標：把 CloudHime 做成一個穩定的 Windows 螢幕 OCR 翻譯器，可以公開展示、測試，並開始定價。
- 負責人：Owner / Codex
- 優先級：P0
- 標籤：ocr, translation, performance, packaging, monetization, windows

## 目標說明

CloudHime 的方向是做出有點像 Google Lens 的桌面工作流：擷取螢幕文字、快速 OCR、清楚翻譯，然後把結果顯示在原文附近。短期目標不是把所有功能一次做完，而是先證明目前這個 App 穩定、準、快，而且可以拿去做公開 demo。

## 成功條件

- 主要 Python 檔案可以通過語法檢查與基本啟動檢查。
- 設定視窗、OCR 後端面板、全域熱鍵與翻譯流程都沒有已知阻塞。
- 有一組 20-50 筆的 OCR 與翻譯測試集。
- Benchmark 可以回報 OCR 命中率、翻譯品質註記與失敗案例。
- 打包後的 App 可以在乾淨的 Windows 機器上啟動，並清楚處理後端缺失情況。
- README、隱私說明與發佈定位都清楚到足以對外展示。

## 限制

- 目前階段只支援 Windows 10 / 11。
- 公開版不能內嵌 API key。
- 在品質與打包驗證完成前，不要急著上 Steam。
- 免費與付費翻譯服務都可能有 rate limit，所以備援與提示很重要。
- 商業文案必須和實際交付內容一致。

## 非目標

- 不做瀏覽器外掛。
- 不做手機 App。
- 不做遊戲作弊或 hook 型作弊工具。
- 不承諾在所有場景都取代 Google Lens。
- 不做大型帳號系統或重型雲端計費堆疊。

## 第一個里程碑

做出可公開 demo 的候選版：可以穩定啟動、掃描、翻譯、記錄錯誤，並有可重複的品質與速度驗證集合。

## 主要風險

- OCR 與翻譯品質會跟來源圖片變動，所以一定要有測試集。
- 打包環境可能和開發環境不同，導致缺少 OCR 後端卻沒發現。
- 全域熱鍵衝突很容易破壞第一次使用的印象。
- README 或商店文案如果還是亂碼，信任會直接掉很多。

## 市場備註

- Thaluna 這類工具說明了這個市場確實接受螢幕翻譯，而且會在意預設、回收袋、雲端 AI 等便利性。
- Steam 上已經有類似的 OCR 翻譯工具，代表需求存在，但也代表品質與呈現會被放大檢視。
- Steam 有 100 美元的產品費與完整審核流程，所以先用便宜的方式驗證需求比較合理。
- Microsoft Store 對這種 Windows 工具更自然，但也還是需要好的 demo 和清楚的文件。
